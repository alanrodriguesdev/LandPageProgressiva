# Landing Page Progressivas

Landing page estática em Next.js 15 para divulgação de serviços de progressiva e cabeleireiro.

## Requisitos

- Node.js instalado
- npm disponível

## Comandos

- `npm run dev` — ambiente local
- `npm run build` — build de produção
- `npm run start` — servidor de produção local
- `npm run lint` — lint do projeto
- `npm run typecheck` — checagem de tipos
- `npm run test` — testes unitários
- `npm run test:e2e` — testes end-to-end
- `npm run check:pendencias` — bloqueia publicação com dados provisórios

## Conteúdo editável

Os dados ficam centralizados em `src/content/`:

- `negocio.ts`
- `servicos.ts`
- `beneficios.ts`
- `trabalhos.ts`
- `depoimentos.ts`
- `perfil.ts`

## Publicação

O deploy alvo é a Vercel. Antes de publicar, substitua todos os valores marcados com `[PENDENTE]`.
